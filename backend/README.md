# classManage organisation_service

NestJS API built with TypeScript.

## Getting started

```bash
npm install
npm run start:dev
```

The server listens on port `3003` by default. Set `PORT` to use a different port. The starter endpoint is `GET /api`.

## Commands

- `npm run build` — compile to `dist/`
- `npm run start:dev` — run in watch mode
- `npm run start:prod` — run the compiled application
- `npm run lint` — lint TypeScript source
